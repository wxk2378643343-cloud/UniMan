# 有漏洞版启动文档

## 1. 项目说明

当前启动的是 `with-vuln` 版本，即高校后勤服务管理系统的漏洞研究演示版。

技术栈如下：
- 后端：`Python + FastAPI`
- 前端：`Vue 3 + Vite`
- 数据库：`SQLite`

## 2. 项目目录

主要目录如下：

```text
UniMan/
├─ doc/
├─ with-vuln/
│  ├─ backend/
│  └─ frontend/
└─ without-vuln/
```

本次只需要启动：
- `with-vuln/backend`
- `with-vuln/frontend`

## 3. 环境要求

请确保本机已安装：

- `Python 3.11` 或兼容版本
- `Node.js 22+`
- `npm`

## 4. 启动后端

在终端进入后端目录：

```powershell
cd G:\project\UniMan\with-vuln\backend
```

执行启动命令：

```powershell
python -m uvicorn app.main:app --reload --port 8000
```

启动成功后，后端地址为：

```text
http://127.0.0.1:8000
```

健康检查接口：

```text
http://127.0.0.1:8000/api/health
```

如果看到返回：

```json
{"status":"ok"}
```

说明后端启动成功。

## 5. 启动前端

新开一个终端，进入前端目录：

```powershell
cd G:\project\UniMan\with-vuln\frontend
```

第一次运行需要安装依赖：

```powershell
npm install
```

安装完成后执行：

```powershell
npm run dev
```

启动成功后，前端地址一般为：

```text
http://127.0.0.1:5173
```

## 6. 登录系统

打开浏览器访问：

```text
http://127.0.0.1:5173
```

默认管理员账号：

```text
用户名：admin
密码：admin123
```

## 7. 当前版本已实现页面

目前可以查看和演示的页面包括：

- 登录页
- 业务总览页
- 报修工单页
- 公告通知页
- 安全研究页

## 8. 启动顺序建议

建议按以下顺序启动：

1. 先启动后端
2. 再启动前端
3. 最后浏览器访问前端地址

## 9. 常见问题

### 9.1 前端无法访问接口
请先确认后端是否正常启动，并检查：

- 后端是否运行在 `8000` 端口
- 前端是否运行在 `5173` 端口

### 9.2 前端首次运行报依赖缺失
执行：

```powershell
npm install
```

然后重新执行：

```powershell
npm run dev
```

### 9.3 后端端口被占用
如果 `8000` 端口被占用，可改为其他端口，例如：

```powershell
python -m uvicorn app.main:app --reload --port 8001
```

如果修改了后端端口，记得同步修改前端配置文件：

文件位置：
[vite.config.js](G:\project\UniMan\with-vuln\frontend\vite.config.js)

将代理地址从：

```js
target: "http://127.0.0.1:8000"
```

改为对应端口。

## 10. 关闭服务

在对应终端窗口中按：

```text
Ctrl + C
```

即可关闭前端或后端服务。

## 11. 补充说明

`with-vuln` 是研究演示版，当前版本故意保留了部分安全缺陷，用于后续与 `without-vuln` 修复版进行对比展示，不可直接用于真实生产环境。
