# 双版本启动说明

## 1. 说明

当前项目分为两个版本：

- `with-vuln`：有漏洞版本
- `without-vuln`：修复版本

两个版本已经使用不同的前后端端口，避免运行时冲突。

## 2. 端口分配

### 2.1 有漏洞版
- 后端端口：`8000`
- 前端端口：`5173`

### 2.2 修复版
- 后端端口：`8001`
- 前端端口：`5174`

## 3. 有漏洞版启动方式

### 3.1 启动后端

```powershell
cd G:\project\UniMan\with-vuln\backend
python -m uvicorn app.main:app --reload --port 8000
```

### 3.2 启动前端

```powershell
cd G:\project\UniMan\with-vuln\frontend
npm run dev
```

### 3.3 访问地址

- 前端地址：`http://127.0.0.1:5173`
- 后端地址：`http://127.0.0.1:8000`

## 4. 修复版启动方式

### 4.1 启动后端

```powershell
cd G:\project\UniMan\without-vuln\backend
python -m uvicorn app.main:app --reload --port 8001
```

### 4.2 启动前端

```powershell
cd G:\project\UniMan\without-vuln\frontend
npm run dev
```

### 4.3 访问地址

- 前端地址：`http://127.0.0.1:5174`
- 后端地址：`http://127.0.0.1:8001`

## 5. 默认测试说明

建议同时打开两个终端窗口，分别运行前端和后端。

如果需要同时测试两个版本，可以按下面方式运行：

1. 启动 `with-vuln` 后端和前端
2. 启动 `without-vuln` 后端和前端
3. 浏览器分别访问不同端口进行对比

## 6. 推荐测试地址

### 6.1 有漏洞版
- `http://127.0.0.1:5173`

### 6.2 修复版
- `http://127.0.0.1:5174`

## 7. 注意事项

1. 如果前端无法访问后端，请确认对应版本的后端是否已经启动。
2. 如果端口被占用，请先关闭已有服务，或同步修改对应版本的端口配置。
3. 两个版本不要混用前后端，否则会出现接口不匹配的问题。
